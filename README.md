# 🔌 ProxyBridge

ProxyBridge — это локальная система управления прокси для Google Chrome, обходящая ограничения безопасности Manifest V3. Она использует легковесный Python-контроллер для чтения запущенных прокси-контейнеров из Docker Compose и расширение для браузера с мгновенным переключением и визуальной индикацией.

---

## 🏗 Архитектура проекта

1. **Docker Compose (`docker-compose.yml`)**: Запускает локальный API-контроллер и прокси-контейнеры (`gost`) с фиксированным префиксом `proxy_*`, которые принимают трафик из браузера без авторизации и проталкивают его на внешние шлюзы с логинами и паролями.
2. **Python API (`server/`)**: Опрашивает Docker Socket (`/var/run/docker.sock`), находит активные контейнеры по маске `proxy_*` и отдает их порты в формате JSON.
3. **Chrome Extension (`extension/`)**: Интерфейс с кнопкой включения/выключения, динамическим списком прокси, подсветкой активного узла и цветовым индикатором на иконке (`ON`).

### 2. Инструкция по запуску

## 🚀 Инструкция по запуску


### Шаг 1. Запуск инфраструктуры (Docker Compose)

В корне проекта выполни команду для сборки и запуска контейнеров:

```bash
docker compose up -d --build --remove-orphans

```

### Шаг 2. Установка расширения в Chrome

1. Открой `chrome://extensions/`
2. Включи **«Режим разработчика»** (Developer mode).
3. Нажми **«Загрузить распакованное расширение»** и выбери папку `extension/`.

### 3. Управление, добавление проксей и использование
## 🛠 Управление и добавление проксей

### Как добавить новый прокси-сервер?
Добавь новый сервис в файл `docker-compose.yml` под префиксом `proxy_`:

```yaml
  gost-new-location:
    image: gogost/gost:latest
    container_name: "proxy_germany_berlin" # Обязательно начинать с "proxy_"
    command:
      - "-L=:7003"                      # Локальный порт
      - "-F=http://user:pass@ip:port"    # Креды от Proxy Solution
    ports:
      - "7003:7003"
    restart: unless-stopped

```

После этого пересобери контейнеры:

```bash
docker compose up -d --build --remove-orphans

```

## 🖥 Как пользоваться расширением

1. Кликни по иконке **ProxyBridge** в панели браузера.
2. Выбери нужную прокси-локацию (активная подсветится зеленым с галочкой `✓`).
3. На иконке расширения загорится индикатор **ON**.
4. Кнопка **«Выключить (Direct)»** возвращает прямой трафик.
